Lolirine Storage Availability

Gérez la disponibilité de vos box de stockage sur le e-commerce

Fonctionnalités principales

Statut de disponibilité

Définissez le statut de chaque box : Disponible, Loué, Réservé ou En maintenance. Le statut est visible sur le e-commerce avec un badge coloré.

Bouton Rendez-vous

Affichez automatiquement un bouton "Contactez-nous" sur les box disponibles qui redirige vers la prise de rendez-vous Odoo native.

Configuration globale

Paramétrez le comportement par défaut dans les Paramètres généraux : activation du bouton, type de rendez-vous, texte personnalisé.

Override par produit

Surchargez la configuration globale sur chaque produit individuellement : forcez ou masquez le bouton, choisissez un type de rendez-vous spécifique.

Comment ça marche ?

  1. Configuration : Allez dans Configuration > Paramètres généraux > Box de Stockage
  2. Activation : Cochez "Activer le bouton rendez-vous" et sélectionnez un type de rendez-vous
  3. Produits : Marquez vos produits comme "Box de stockage" dans leur fiche
  4. Statut : Définissez le statut de chaque box dans l'onglet "Box de Stockage"
  5. E-commerce : Le bouton apparaît automatiquement sur les box "Disponibles"

Dépendances

Ce module nécessite les modules suivants :

  • Website Sale (e-commerce)
  • Website Appointment (rendez-vous en ligne)
  • Product (produits)
