⚡ INSTALLATION EN 3 ÉTAPES
───────────────────────────────────────────────────────────────────────────────

ÉTAPE 1 : Créer le module
──────────────────────────

Option A - Script automatique (le plus rapide) :
  
  cd votre-projet-odoo
  bash create_module.sh
  
  ✅ Le script crée automatiquement tous les fichiers !


Option B - Copier-coller manuel :

  Consultez le fichier MODULE_COMPLET_ODOO_18.1.txt et copiez le contenu
  de chaque fichier dans votre structure :
  
  box_contact_redirect/
  ├── __init__.py
  ├── __manifest__.py
  ├── controllers/
  │   ├── __init__.py
  │   └── main.py
  ├── models/
  │   ├── __init__.py
  │   └── product_template.py
  └── views/
      ├── product_template_views.xml
      └── website_sale_templates.xml


ÉTAPE 2 : Pousser vers Odoo.sh
───────────────────────────────

  git add box_contact_redirect/
  git commit -m "Add box_contact_redirect module v18.1.1.0"
  git push origin master
  
  ⏳ Attendez que le build soit terminé (vérifiez le dashboard Odoo.sh)


ÉTAPE 3 : Installer dans Odoo
──────────────────────────────

  1. Paramètres > Activer le mode développeur
  2. Apps > Mettre à jour la liste des Apps
  3. Rechercher "Box Contact Redirect"
  4. Cliquer sur Installer
  
  ✅ C'est installé !

═══════════════════════════════════════════════════════════════════════════════

✨ UTILISATION
───────────────────────────────────────────────────────────────────────────────

Configuration d'un box :
────────────────────────

  1. Ventes > Produits > Ouvrir un produit (box)
  2. Onglet "Ventes" > Section "Gestion Box"
  3. Cocher : ☑ Box disponible
  4. Cocher : ☑ Rediriger vers contact
  5. Publier sur le site web
  
  🎉 Le bouton "Nous contacter" apparaît maintenant sur le site !


Résultat sur le site :
──────────────────────

  • Page produit : Bouton "Nous contacter pour ce box"
  • Catalogue : Bouton "Nous contacter"
  • Clic → Formulaire de contact avec infos pré-remplies


Quand un box est loué :
────────────────────────

  • Décocher : ☐ Box disponible
  • Le box revient au mode normal (bouton "Ajouter au panier")

🐛 RÉSOLUTION DE PROBLÈMES
───────────────────────────────────────────────────────────────────────────────

Le module n'apparaît pas :
  → Apps > Mettre à jour la liste des Apps
  → Vérifier les logs Odoo.sh

Erreur lors de l'installation :
  → Vérifier que website_sale est installé
  → Consulter MODULE_COMPLET_ODOO_18.1.txt pour la syntaxe complète

Le bouton ne change pas :
  → Vérifier les deux cases cochées sur le produit
  → Vider le cache (Ctrl+F5)
  → Vérifier que le produit est publié

Ancienne version installée avec erreur :
  → Désinstaller complètement
  → Supprimer le dossier box_contact_redirect/
  → Réinstaller la nouvelle version
