🏊 Lolirine AI Chat Assistant

Assistant IA intelligent pour votre site e-commerce piscine & spa

Fonctionnalités principales

  • 💬 Chat IA en temps réel — Propulsé par Claude (Anthropic)
  • 🔍 Recherche web intégrée — L'IA peut chercher sur internet pour compléter ses réponses
  • 📦 Recherche produits — Recommandation automatique de produits du catalogue
  • 📊 Historique complet — Toutes les conversations sauvegardées côté backend
  • ⭐ Système de notation — Les clients peuvent évaluer leur satisfaction
  • ⚙️ Configuration complète — Prompt, couleurs, limites, modèle IA
  • 📱 Responsive — Fonctionne sur mobile et desktop

Configuration rapide

  1. Installez le module
  2. Allez dans Assistant IA → Configuration → Paramètres
  3. Entrez votre clé API Anthropic
  4. Personnalisez le prompt système et l'apparence
  5. C'est prêt ! Le widget apparaît sur toutes les pages du site
