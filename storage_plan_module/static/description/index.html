Plan Interactif Garde-Meubles

Gestion et réservation en ligne de vos boxes de stockage

Fonctionnalités principales

Plan interactif

Visualisez tous vos boxes sur un plan interactif avec code couleur selon leur statut. Les clients peuvent facilement identifier les boxes disponibles et accéder aux détails.

Visualisation 3D

Chaque box dispose d'une représentation 3D interactive permettant aux clients de mieux comprendre les dimensions et le volume disponible.

Réservation simplifiée

Les clients peuvent réserver un box directement depuis le site web :

  • Demande de rendez-vous pour visiter
  • Réservation immédiate en ligne
  • Formulaire simple et intuitif
  • Confirmation automatique

Gestion complète depuis Odoo

Interface d'administration complète pour gérer vos boxes, étages et réservations.

  • Gestion des boxes : Créez, modifiez et suivez l'état de chaque box
  • Gestion des étages : Configurez la structure de votre garde-meubles
  • Gestion des réservations : Suivez toutes les demandes et confirmations
  • Statuts multiples : Disponible, occupé, maintenance, nettoyage, etc.
  • Tarification flexible : Prix, frais de dossier, caution personnalisables

Caractéristiques techniques

Backend

  • Modèles Odoo robustes
  • Vues kanban, liste et formulaire
  • Recherches et filtres avancés
  • Droits d'accès configurables

Frontend

  • Interface responsive (mobile-friendly)
  • Visualisation 3D en HTML5 Canvas
  • AJAX pour une expérience fluide
  • Design moderne avec Bootstrap

Installation facile

Le module s'installe en un clic et inclut des données d'exemple pour démarrer rapidement. Documentation complète incluse dans le README.

Compatible avec Odoo 15.0, 16.0 et 17.0
