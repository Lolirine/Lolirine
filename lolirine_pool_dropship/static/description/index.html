Workflow automatisé

1. Commande client reçue
Le client passe commande sur votre site e-commerce.

2. Analyse automatique
Le module analyse tous les fournisseurs éligibles et calcule les marges.

3. Sélection optimale
Le meilleur fournisseur est sélectionné selon vos critères (marge, délai, fiabilité).

4. BC fournisseur généré
Une commande fournisseur est créée automatiquement avec l'adresse du client final.

5. Envoi automatique
Le BC est envoyé au fournisseur par email (emballage neutre requis).

6. Suivi complet
Tracking de livraison, notification client, reporting des marges.

Configuration flexible

Critères de sélection personnalisables :

  • Pondération marge / délai / fiabilité / frais de port
  • Seuil de marge minimum configurable
  • Bonus pour fournisseurs prioritaires ou délais rapides
  • Malus pour fournisseurs peu fiables
  • Règles de marge par catégorie, produit ou fournisseur
